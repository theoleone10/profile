Paperboy

Your newsletters, turned into one short audio brief every morning. Pick the newsletters, the length and the voice.

  1. A script pipeline on GPT-5 mini with per-segment word budgets, so episodes land on the length you picked
  2. Inworld text-to-speech voiced section by section, so every chapter’s start time is exact
  3. Security for App Store review: keychain JWT sessions, ownership checks, signed OAuth state, rate limits, in-app account deletion

Expo · TypeScript · Express · Supabase · Gmail API · OpenAI · Inworld

  • Code for Paperboy on GitHub
More about the build

Solo: app, backend, infra · 2025–26

You sign in with Google and choose which newsletters you want. At the time you set, Paperboy reads the latest issues and writes one script at the length you picked. It records the script in the voice you chose and sends a notification when your episode is ready. Gmail access is read-only, and only the newsletters you chose are ever read.

  • Gmail sync and parsing to find newsletters and pull out the readable text
  • A React Native player with chapters, transcript, archive, background audio and a Live Activity

    Kaeru

    Japanese grammar, a little every day: 421 grammar points from N5 to N1, laid out as train lines. Out now on the App Store.

    1. Type the missing grammar into real sentences; romaji turns into kana as you go, and FSRS schedules the next review
    2. Works fully offline on SQLite, and syncs when you sign in
    3. New in 1.1.0: a full redesign, a kana course, a placement quiz and a built-in deck of the 600 most useful words

    Expo 57 · React Native · TypeScript · SQLite · FSRS · Supabase

    • App Store: Kaeru
    • Code for Kaeru on GitHub
    More about the build

    Solo: design, code, content · 2026

    Each JLPT level is a train line and each grammar point a stop: 421 of them, N5 to N1. Each day you learn a few points, take a quiz, then review earlier ones by typing the missing grammar into real sentences, scheduled with FSRS. Anki decks and a study timer come built in.

    New in 1.1.0

    • A full redesign: softer and rounder, with a new typeface, custom icons and a redrawn Kaeru
    • A kana course, and Kaeru Starter 600, a built-in deck of the 600 most useful words
    • A placement quiz that finds where you are on the grammar lines
    • Drawn profile avatars, today-only new-card limits, a smoother typing screen and iOS 27 support

    Waypass

    The whole cremation workflow, from intake to completion, on one platform for funeral homes, crematoriums and shipping partners.

    1. Booking flow: the funeral home proposes times, the crematorium answers from a private emailed link, the home confirms
    2. Every booking step written to an audit log of booking events
    3. PostGIS search for nearby partners, shown on Google Maps

    React 19 · Node · Express · Supabase · PostGIS · Tailwind

    • Code for Waypass on GitHub
    More about the build

    Multi-tenant SaaS · 2026

    Funeral homes still run cremations with phone calls and paper. Waypass connects them with crematoriums and shipping partners, follows each case from intake to completion, and gives families their own view of a case’s progress.

    • Case pipeline covering intake, custody, documents and completion
    • Family portal, financial dashboard, in-app inbox and Resend email
    • Workspaces with roles, and a Cmd+K palette that searches everything

    More about the work

    QMIND × Distributive · 2026–now

    QMIND and Distributive are building a proof-of-concept, publicly available package for running federated learning on the Distributive Compute Platform. Training data stays on the machines that hold it, and only model information moves through DCP. There are two model tracks: logistic regression and random forest.

    • Contributing to the shared specs, which need a reviewer from the other track
